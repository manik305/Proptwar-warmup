# Travel Planning & Experience Engine Design System

## Overview
This design system is for a dynamic travel planning web application specifically targeting top tourist destinations in India (e.g., Goa, Rajasthan, Kerala, Taj Mahal). The platform aims to inspire travelers while providing an intuitive, AI-driven trip-planning chatbot.

## Aesthetics & Vibe
- **Theme:** Vibrant, immersive, and premium. It should reflect the rich culture, colors, and landscapes of India, while remaining sleek and modern.
- **Style:** Glassmorphism, smooth gradients, large high-quality imagery, and subtle micro-animations.
- **Color Palette:** 
  - Primary: A rich, warm saffron or vibrant sunset orange, symbolizing energy and culture.
  - Secondary: Deep ocean blue or emerald green, representing nature and tranquility.
  - Background (Dark Mode): Deep slate or midnight blue (`#0f172a` to `#020617`) to make images and vibrant colors pop.
  - Background (Light Mode): Off-white or soft cream (`#fafafa` to `#f1f5f9`) for a clean, elegant look.
  - Accents: Gold/Yellow for highlights and interactive elements.
- **Typography:** Modern sans-serif fonts (e.g., *Inter*, *Outfit*, or *Plus Jakarta Sans*) for clean readability and a premium feel. Use varied font weights to establish clear hierarchy.

## Shape & Structure
- **Shapes:** Soft, rounded corners for cards, buttons, and input fields (e.g., `border-radius: 12px` or `16px`).
- **Layout:** Spacious layouts, utilizing CSS Grid and Flexbox for responsive design. The interface should not feel cluttered.
- **Cards:** Destination cards and itinerary blocks should use subtle drop shadows and glassmorphism (translucency + background blur) to appear floating over the background.

## Key Components
1. **Chatbot Interface:** 
   - A floating, sleek chat window or a dedicated chat section with distinct user and AI message bubbles.
   - Smooth slide-in animations.
2. **Destination Showcase:** 
   - Large hero images or carousels highlighting iconic Indian landmarks.
   - Overlay text with clean typography.
3. **Dynamic Itinerary Timeline:**
   - A vertical or horizontal timeline displaying the generated trip plan, using icons and small thumbnail images for each step.
4. **Interactive Elements:**
   - Buttons with hover effects (e.g., slight scaling, gradient shift, or shadow increase).

## Mobile Responsiveness
- The design must adapt seamlessly to mobile devices, ensuring the chatbot remains easily accessible and the destination imagery scales appropriately.
